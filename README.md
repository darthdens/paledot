# Pale Dot

Pale Dot is an interactive 3D explorer, from Earth to the edge of the observable universe, created by [Dens Akoka](https://dens.so). Explore at [paledot.org](https://paledot.org).

### Explore
Navigate planets, moons, stars and larger cosmic structures; follow objects, compare sizes and take guided tours. Solar System bodies share a simulation clock, with true-scale sizes and distances. Screen-size machine markers are not to scale.

### Left Behind
Built during NASA Space Apps Challenge 2026 (14–15 November), Left Behind brings NASA hardware into the same universe: Apollo 11, the Apollo 15–17 lunar rovers, Viking 1, Opportunity, Ingenuity and Voyagers 1 and 2. Guided tours combine dated journeys, archival imagery and credited sources. Cached JPL Horizons trajectories and NASA imagery are used; missing data and simplified representations are identified. See [HACKATHON.md](HACKATHON.md) and [CREDITS.md](CREDITS.md).

### Development
Built with TanStack Start, React, TypeScript, Three.js / React Three Fiber, Tailwind CSS and astronomy-engine. One codebase also serves [Cosmos Explorer](https://cosmos.dens.so), with separate branding. Run the shared commands below; preview Pale Dot at `/?site=paledot` or Cosmos at `/?site=cosmos`.
